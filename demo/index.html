Custom tools

Three buttons that are not built in, added without forking. The first two are declared as plain objects; the third is a class, which is what you need when a tool builds its own markup. Hover each one, then click with and without a selection.

Things to try:

  • Callout and Signature are plain objects. Select a line, press Callout.
  • Highlight adds a shortcut. Hover it to see Ctrl+Shift+H in the tooltip, then press the shortcut with and without a selection.
  • Embed video is a class, because it opens a dialog. Its caption field has a real toolbar built by createToolbar, and the caption is rendered with renderMarkdown.

The embed inserts an <iframe>, which DOMPurify strips by default, so this editor also passes a sanitizer allowing it. Remove that option and the embed vanishes from the preview — allowing iframes is the host application's decision, not the editor's.
