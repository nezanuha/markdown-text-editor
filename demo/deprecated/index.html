Open the console. Every editor below is configured the way 1.x asked for, and every one of them still works. The console says what each old form is called now, once per form however many editors use it.

Three are console.info: renamed, still supported, no removal planned. One is console.warn with a version on it, because it is the one that costs you something to keep.

1. labels, which is locale now

The tooltips are Spanish, from the old option name. Hover Bold.

2. label, which is an aria-label

Inspect the textarea: the option wrote the attribute for you, which you can write yourself.

3. variables inside the toolbar array

The dropdown is there and the preview still substitutes the samples, from the old place in the config.

4. image.fileInput — the one with a date on it

The image dialog still uploads to the old uploadUrl. Now try pasting or dropping an image: nothing happens, which is what the warning is about.

5. A second editor on the same old forms

Says nothing. The notices are keyed to the form, not to the editor, so a page carrying twelve of these has one thing to read rather than twelve.
